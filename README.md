# ⏳ Countdown Timer — 3 languages

A simple CLI countdown timer that takes a target date/time and shows remaining days, hours, minutes, and seconds. Implemented in **Python**, **JavaScript (Node.js)**, and **C++**.

## 🚀 Run

| Language | File | Run command |
|:---|:---|:---|
| Python | `python/timer.py` | `python timer.py` |
| JavaScript | `javascript/timer.js` | `node timer.js` |
| C++ | `cpp/timer.cpp` | `g++ timer.cpp -o timer && ./timer` |

## 📝 How to use

Enter a target date and time (YYYY-MM-DD HH:MM:SS). The program will calculate and display remaining time.
